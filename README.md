# Обнаружение мошенничества с использованием нейронной сети

# Описание проекта

Этот проект представляет собой реализацию искусственной нейронной сети (на основе Keras и TensorFlow) для выявления мошеннических транзакций по банковским картам.  
Для обучения используется подмножество из 1000 транзакций из датасета, содержащего 30 признаков и метку класса ('0' — обычная, '1' — мошенническая).


# Данные

Используется файл `creditcard.csv`, содержащий:

- 30 анонимизированных числовых признаков (V1–V30)
- Признак 'Class':
  - '0' — нормальная транзакция
  - '1' — мошенническая транзакция


# Архитектура модели

- 4 полносвязных слоя по 30 нейронов с активацией ReLU
- Выходной слой с 2 нейронами и активацией Softmax
- Функция потерь: 'categorical_crossentropy'
- Оптимизатор: 'SGD'
- Метрика: 'accuracy'

# Этапы обработки

1. Загрузка и предобработка данных
2. Разделение на обучающую и тестовую выборки
3. Нормализация признаков ('StandardScaler')
4. One-hot кодирование классов
5. Построение и обучение нейронной сети
6. Визуализация точности и функции потерь
7. Расчёт точности общей и точности только по мошенническим транзакциям

# Результаты

После обучения модель выводит:

- Точность обучения и теста по эпохам (Accuracy)
- Функция потерь по эпохам (Loss)
- Отдельная точность на мошеннических транзакциях
