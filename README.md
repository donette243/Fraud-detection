# Обнаружение мошеннических банковских транзакций с использованием нейронных сетей

## 1. Описание проекта

Проект посвящён разработке модели машинного обучения для автоматического обнаружения мошеннических операций по банковским картам на основе анализа данных о транзакциях.

Для решения задачи используется нейронная сеть прямого распространения (Feedforward Neural Network), реализованная с помощью **TensorFlow/Keras**.

Модель выполняет бинарную классификацию транзакций, определяя их принадлежность к одному из двух классов:

- **0 — легитимная транзакция**
- **1 — мошенническая транзакция**

Основная задача проекта — исследование применения нейронных сетей для выявления потенциально мошеннических финансовых операций на основе характеристик транзакций.

## 2. Основные возможности

- Загрузка и предварительная обработка данных банковских транзакций.
- Подготовка признаков для обучения нейронной сети.
- Стандартизация числовых признаков с использованием `StandardScaler`.
- Построение многослойной полносвязной нейронной сети.
- Обучение модели для бинарной классификации транзакций.
- Оценка точности классификации на тестовой выборке.
- Анализ доли правильно обнаруженных мошеннических операций.
- Сохранение обученной модели в формате `.keras`.

## 3. Используемые данные

В проекте используется набор данных `creditcard.csv`, содержащий сведения о банковских транзакциях и метки классов.

Целевая переменная `Class` определяет тип транзакции:

| Значение | Класс |
|---|---|
| `0` | Легитимная транзакция |
| `1` | Мошенническая транзакция |

В текущей реализации для эксперимента используются **первые 1 000 записей** исходного набора данных.

Данные разделяются на две части:

| Выборка | Доля |
|---|---|
| Обучающая | 90 % |
| Тестовая | 10 % |

Перед обучением числовые признаки стандартизируются с помощью `StandardScaler`.

Такой подход позволяет привести признаки к сопоставимому масштабу и подготовить их для обработки нейронной сетью.

## 4. Архитектура нейронной сети

Модель реализована с использованием последовательной архитектуры `Sequential` библиотеки Keras.

Основные компоненты:

| Компонент | Описание |
|---|---|
| Входные данные | Числовые признаки транзакций |
| Скрытые слои | 4 полносвязных слоя по 30 нейронов |
| Выходной слой | Классификация на два класса |
| Выходная активация | Softmax |
| Оптимизатор | SGD |
| Количество эпох | 30 |

Нейронная сеть анализирует входные признаки и формирует оценки принадлежности транзакции к двум классам.

Для получения итогового класса используется выход модели.

## 5. Обучение и оценка модели

Обучение выполняется на подготовленных данных банковских транзакций.

Процесс включает следующие этапы:

1. Загрузка исходного CSV-файла.
2. Выделение признаков и целевой переменной.
3. Разделение данных на обучающую и тестовую выборки.
4. Стандартизация признаков.
5. Построение нейронной сети.
6. Обучение модели в течение 30 эпох.
7. Получение предсказаний и оценка результатов.
8. Сохранение обученной модели.

Для оценки используются два показателя:

**Accuracy** — доля правильно классифицированных транзакций среди всех рассмотренных примеров.

**Доля обнаруженных мошеннических транзакций (Recall для класса 1)** — доля мошеннических операций, которые модель правильно определила как мошеннические.

При анализе результатов важно учитывать дисбаланс классов: высокая общая точность не всегда означает высокое качество обнаружения мошенничества.

В текущей реализации тестовая выборка также используется для валидации в процессе обучения, поэтому полученные результаты следует рассматривать как экспериментальные.

Основные файлы репозитория:

```text
Fraud-detection/
├── PRO3.py
├── requirements.txt
├── модель_мошенничество.keras
└── README.md
```

Назначение файлов:

- `PRO3.py` — основной скрипт подготовки данных, обучения и оценки нейронной сети.

## 8. Установка и запуск

### 8.1. Клонирование репозитория

```bash
git clone https://github.com/donette243/Fraud-detection.git
```

Переход в каталог проекта:

```bash
cd Fraud-detection
```

### 8.2. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 8.3. Подготовка данных

Для запуска необходимо подготовить файл `creditcard.csv` с соответствующей структурой данных.

В скрипте `PRO3.py` используется абсолютный путь к CSV-файлу, соответствующий исходному окружению разработки.

Перед запуском необходимо изменить этот путь на расположение файла на текущем компьютере.

### 8.4. Запуск программы

После подготовки данных и настройки пути выполните:

```bash
python PRO3.py
```

Скрипт выполняет подготовку данных, обучение модели, получение предсказаний и оценку качества классификации.
